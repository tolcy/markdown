加密与密钥

为不同文稿选择不同密钥。软件会在这台电脑的当前 Windows 账户中安全记住密钥，下次打开时自动解密。

请另行保存原始密钥。换电脑或重装系统后，需要重新添加相同密钥。加密只保护文稿正文，不隐藏文件名，也不加密图片附件或导出文件。

请使用 Windows 桌面版管理密钥和加密文稿。

快捷键

常用操作一览。

  • Ctrl+B 加粗
  • Ctrl+I 斜体
  • Ctrl+D 删除线
  • Ctrl+1…6 一至六级标题
  • Ctrl+S 保存
  • Ctrl+F 查找
  • Ctrl+Click 打开链接
  • Ctrl+H 跳到标题
  • Ctrl+Shift+H 替换
  • Ctrl+P 按文件名打开
  • Ctrl+U 代码块语言
  • Ctrl+Shift+I 字数统计
  • Esc 关闭查找 / 快速打开
  • Enter 查找下一个
  • Shift+Enter 查找上一个
  • ( 【 * ` 自动成对，光标落在中间
